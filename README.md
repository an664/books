# НЕСПЯЩИЕ

## Книга первая. «Мёртвый час»

*Мистический триллер. Петербург, октябрь, наше время.*

Каждую ночь ровно в три Петербург останавливается. Дождь висит в воздухе, люди замирают на полуслове, у застывших нет пульса. Но несколько десятков человек в это время не спят. У каждого из них — свой завод: у кого-то четыре минуты ночи, у кого-то час. А когда неспящий умирает, вся его ночь уходит к тому, кто стоит ближе всех.

Фельдшер скорой Глеб Савельев держал за руку умирающего старика-часовщика. Теперь у него самая длинная ночь в городе. И весь город, который не спит, хочет его смерти.
